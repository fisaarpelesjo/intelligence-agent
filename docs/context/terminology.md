# Terminology

- SDD: Specification Driven Development.
- TDD seletivo: ciclo red, green, refactor aplicado onde comportamento deterministico justifica.
- MADR: Markdown Architectural Decision Records.
- Checkpoint: registro validado do estado, evidencias e proxima acao.
- Convergence: verificacao de alinhamento entre briefing, spec, plano, tarefas e implementacao.
